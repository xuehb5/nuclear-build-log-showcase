# 核电地图操作示例：从省份定位到厂址与机组

**[简体中文](map-guide.md) · [English](map-guide.en.md) · [返回介绍页](../README.md)**

以下图片来自2026年10月29日实际运行网站。操作只选择和查看项目，不修改台账；截图中的阶段与数量反映当时的维护记录。

## 第一步：点击省份本身

在地图中点击广东省的省级区域。省份高亮后，地图显示廉江、陆丰、太平岭和台山的厂址点，右侧切换为“广东核电项目”。示例中共有4个项目、16台在册机组；右侧列表可继续滚动查看。

![点击广东省后的实际地图和项目清单](../assets/nuclear-map.png)

右侧按项目列出所属公司和机组代码；每台机组显示堆型及当前阶段。阶段文字采用与进度可视化对应的颜色，便于从省级分布快速查看工程情况。

## 第二步：点击厂址点或项目名称

点击地图上的陆丰厂址点，或右侧“陆丰核电项目”名称。地图只显示选中厂址的点并标注“陆丰”，右侧陆丰项目卡片同时突出显示；省内其他项目仍保留在列表中以便比较和继续选择。

![点击陆丰项目后的实际定位效果](../assets/nuclear-map-site.png)

这体现地图与项目清单的双向选择：可以先选省份再选厂址，也可以从右侧项目名称回到对应地理位置。重新点击某省份，可回到该省全部厂址点的显示状态。

## 第三步：进入机组台账核对

点击右侧的具体机组代码，例如 LUFENG-5，可进入“项目状态”检索对应机组，核对工程节点、日期、所属公司与堆型。

![已有陆丰项目状态工作台截图](../assets/project-status.png)

地图本身不另外推测机组阶段。新闻经用户确认后，AI 辅助识别与程序校验形成有效更新，或用户手动维护机组时，项目台账、地图和进度可视化读取同一记录。选择省份或厂址只是查看信息，不会触发进度更新。
