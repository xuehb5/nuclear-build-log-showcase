# 自主配置 AI 模型：添加多个 API 与切换模型

**[简体中文](model-guide.md) · [English](model-guide.en.md) · [返回介绍页](../README.md)**

模型配置入口位于“报告生成”的设置中。平台支持保存多个 OpenAI 兼容的 API / 模型配置，并从界面选择当前使用的配置。以下截图来自2026年10月29日实际网站，保留现有配置，没有为展示虚构额外模型或填入密钥。

## 添加与管理 API 配置

依次打开“报告生成 → 设置 → 管理模型”，点击“添加模型”。不同服务商、模型名称或用途可以分别保存为独立配置。

![真实的模型管理与添加窗口](../assets/model-management.png)

| 配置项 | 用途 |
| --- | --- |
| 显示名称 | 便于识别的配置名称，例如按用途命名 |
| 接口地址 | 服务方提供的 OpenAI 兼容 API 地址 |
| 模型名称 | 服务方实际支持的模型标识 |
| API Key | 用户自己的接口密钥，每份配置分别保存；截图中为空 |
| 最长等待时间 | 接口请求允许等待的时间 |
| 申请Key网址、备注 | 可选的管理信息，便于后续维护 |

界面提供“保存并测试”和“保存并使用”。已有配置可以编辑或删除。接口能否调用取决于配置、服务方可用性及模型权限；界面中的显示名称只是便于识别，实际请求使用填写的模型标识。

## 选择与切换模型

返回“设置 → 生成模型”。已配置 API 的模型会列在这里；点击希望使用的配置，将其设为当前模型。可以保存多份配置，并按需要切换。

![真实的模型选择和当前标记](../assets/model-selection.png)

切换后的配置用于后续模型调用。已有生成内容会继续保留，不会仅因切换就被自动改写；需要新模型处理某篇报告时，再使用对应生成或重新生成操作。

## 与平台其他 AI 工作流的关系

报告生成、新闻确认的语义复核，以及监管文件归档中启用的 AI 辅助会复用当前选中的 API 配置。新闻与监管链路仍由程序校验原文证据并执行实际变更；模型管理不改变用户确认与程序兜底的边界。

未配置 API 时保留原有规则处理路径；本地翻译与 API 配置属于不同能力。请勿在公开反馈中提交 API Key，截图中的密码输入框始终为空。
