# 从新闻核对到工程报告

本导览使用平台实际界面的截图。所有机组、来源、事件与日期均为虚构演示内容，不代表真实核电项目。

## 收集后先核对工程事件

新闻卡片将“新闻发布日期”和“正文中的工程日期”分开显示。读者可以核对进度摘要，展开原文和日期依据，人工更正日期，再决定是否确认。

下图中的演示事件发生在10月18日，新闻发布日期为10月20日。两个日期承担不同用途：前者用于工程记录，后者用于新闻归类。

![新闻工作台](../assets/news-workspace.png)

## 在项目台账中维护节点

项目状态集中呈现机组阶段、堆型与工程节点。新闻确认后的状态判断与人工维护都作用于项目记录；进度视图读取更新后的项目数据。

下面四台虚构机组用于展示规划、土建、安装和调试阶段，不是实际机组清单。

![项目台账](../assets/project-status.png)

## 选入报告，编辑并核对事实

报告工作台保留本期文章列表、工程编辑内容和事实核查区。用户可以修改标题、摘要、正文与日期，核对来源证据，导出单篇或整期报告。

![报告工作台](../assets/report-workspace.png)
